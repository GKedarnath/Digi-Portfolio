# G. Kedarnath Reddy — Digital Portfolio

A responsive, static portfolio site with a welcome page and a separate portfolio page, ready to publish with GitHub Pages.

## Publish with GitHub Pages

1. Create a new repository on GitHub named `kedarnath-portfolio`. Choose the visibility you want; a public GitHub Pages site can be viewed by anyone.
2. Upload the contents of this folder to the repository's `main` branch. Keep `index.html` and `portfolio.html` at the repository root and include `.github/workflows/deploy-pages.yml`.
3. In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions**.
4. Open the **Actions** tab. The workflow publishes the site when files are pushed to `main`. When its first run succeeds, visit **Settings → Pages** for the published website link.

The welcome page links to `portfolio.html`. The website includes the email address and phone number from the supplied profile. Review contact details and repository visibility before publishing.
